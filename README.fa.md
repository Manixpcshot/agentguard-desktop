# 🛡 AgentGuard (ایجنت‌گارد)

**ببینید هوش مصنوعی چه نوشته — پیش از آنکه منتشر شود.**

ایجنت‌گارد یک اپلیکیشن رومیزی متن‌باز و رایگان برای ویندوز است که تغییرات Git
تولیدشده توسط دستیارهای کدنویس هوش مصنوعی را بررسی می‌کند و **کلیدهای API و
رازهای فاش‌شده**، **رگرسیون‌های امنیتی**، **تست‌های خراب یا خراب‌شده**،
**دستورات مخرب** و **تغییرات مشکوک** را همراه با سطح خطر، توضیح و پیشنهاد اصلاح
گزارش می‌کند.

## چرا

ابزارهای کدنویس هوش مصنوعی سریع‌اند، اما گاهی مجموعه تست ناموفق را با حذف
گزاره‌ها «درست» می‌کنند، کلید API داده‌شده را سخت‌کد می‌کنند، اسکریپت راه دور را
به شل لوله می‌کنند یا بی‌صدا راستی‌آزمایی TLS را ضعیف می‌کنند. ایجنت‌گارد به هر
diff تولیدشده توسط هوش مصنوعی همان دقت یک بازبین امنیت دقیق را می‌دهد — آنی،
محلی و رایگان.

## امکانات

- **تحلیل واقعی Git** — بازبینی درخت کاری، تغییرات stage‌شده، پایه ادغام یک
  شاخه، یک کامیت مشخص، بازه نسخه‌ای یا N کامیت اخیر، همراه با نمایش کامل diff.
- **بیش از ۱۴۰ قانون تشخیص در ۷ موتور**، همه به‌صورت محلی:
  | موتور | چه چیزی را می‌گیرد |
  |---|---|
  | رازها و کلیدهای API | توکن‌های AWS/GCP/Azure/GitHub/GitLab/Slack/Stripe/OpenAI/Anthropic، کلیدهای خصوصی، فایل‌های `.env`، رشته‌های اتصال پایگاه داده، مقادیر با آنتروپی بالا |
  | دستورات خطرناک | `rm -rf /`، بمب فورک، `curl \| sh`، غیرفعال‌سازی Defender/فایروال، push اجباری، بازنویسی تاریخچه |
  | رگرسیون‌های امنیتی | تزریق SQL، تزریق دستور، XSS، واحدسازی ناامن، رمزنگاری ضعیف، غیرفعال‌سازی راستی‌آزمایی TLS، اشکالات CORS/کوکی/JWT |
  | یکپارچگی تست | تست‌های رد/تخلیه/حذف‌شده، `.only`، گزاره‌های بدیهی، حذف گزارش‌ها، حذف گام تست CI و سدهای پوشش |
  | تغییرات مشکوک | بلاب‌های base64/hex، سطرهای فشرده، نویسه‌های پهنای‌صفر و هم‌شکل (Trojan Source)، دستکاری `.gitignore`، حذف هوک‌ها/محافظ‌ها، ماندگاری |
  | زنجیره تأمین | اسکریپت‌های جدید `postinstall`، نام‌های جعل‌شده بسته (typosquat)، وابستگی‌های ثابت‌نشده یا رجیستری بیگانه، اختلاف lockfile |
  | سخت‌سازی CI/CD | `pull_request_target` + checkout، تزریق عبارت `${{ }}`، دسترسی `write-all`، نشت راز در لاگ/artifact |
- **امتیاز ریسک و حکم** — امتیاز وزن‌دار ۰ تا ۱۰۰ با بازه‌های امن تا بحرانی و
  حکم قبول / نیازمند بازبینی / مسدود.
- **گزارش‌های کاربردی** — هر یافته توضیح، راه اصلاح، ارجاع CWE و میزان اطمینان
  دارد؛ برون‌بری به **Markdown، HTML یا JSON** به انگلیسی یا فارسی.
- **نظر دوم اختیاری با هوش مصنوعی محلی** — اتصال به [Ollama](https://ollama.com)
  روی دستگاه خودتان (مثلاً `qwen2.5-coder`). برنامه بدون آن هم کامل کار می‌کند.
- **دوزبانه** — انگلیسی (پیش‌فرض) و فارسی با چیدمان کامل راست‌به‌چپ، شامل توضیح
  قوانین و گزارش‌های برون‌بری.
- **ایمنی در طراحی** — ایجنت‌گارد فقط-خواندنی است: هرگز stage، commit، push یا
  ویرایش فایل انجام نمی‌دهد. دو عمل تغییری (پوشاندن راز تشخیص‌شده *همراه پشتیبان*
  و اجرای مجموعه تست) به تأیید صریح و زمان‌دار کاربر نیاز دارند.
- **تاریخچه** — هر اسکن به‌صورت JSON محلی ذخیره می‌شود تا بازبینی‌های گذشته را
  مرور و مقایسه کنید.

## شروع سریع

1. ایجنت‌گارد را نصب و اجرا کنید.
2. روی **انتخاب پوشه پروژه** بزنید و یک مخزن Git محلی انتخاب کنید.
3. مشخص کنید چه چیزی مقایسه شود (پیش‌فرض: درخت کاری) و کدام موتورها اجرا شوند.
4. **شروع اسکن** را بزنید — یافته‌ها را ببینید، diff را باز کنید، گزارش بگیرید.

اختیاری: [Ollama](https://ollama.com) را نصب کنید و `ollama pull qwen2.5-coder:7b`
را اجرا کنید، سپس در برنامه *بازبینی هوش مصنوعی* را فعال کنید.

## ساخت از سورس

نیازمندی‌ها: Node.js ≥ 20، Rust ≥ 1.77 و روی ویندوز
[WebView2 runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
(روی ویندوز ۱۱ از قبل نصب است).

```bash
git clone https://github.com/Manixpcshot/agentguard-desktop.git
cd agentguard-desktop
npm install
npm run tauri dev        # توسعه
npm run tauri build      # نصب‌کننده‌ها در src-tauri/target/release/bundle
```
