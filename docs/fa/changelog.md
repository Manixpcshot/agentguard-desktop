## [0.1.1] - 2026-10-17

### اصلاح‌شده

- **رازها در هر نقطه‌ای که از برنامه بیرون می‌روند ماسک می‌شوند.** اعتبارنامه‌ای که
  توسط موتوری غیر از *رازها* یا توسط هیوریستی بدون قطعه منطبق (مثلاً
  `SEC-SECRET-HIGH-ENTROPY-STRING`) تشخیص داده می‌شد، می‌توانست به‌صورت متن آشکار به
  رابط کاربری، تاریخچه JSON و گزارش‌های برون‌بری Markdown/HTML/JSON برسد. اکنون همه
  یافته‌ها پیش از ارسال، ذخیره یا برون‌بری از `scanner::mask_findings` عبور می‌کنند.
- **پرامپت Ollama واقعاً ماسک می‌شود.** `build_prompt` وعده diff ماسک‌شده می‌داد ولی
  سطرهای خام را می‌فرستاد؛ اکنون `Catalog::mask_secrets_in` توکن‌های شبیه راز را پیش
  از ساخت پرامپت ماسک می‌کند.
- ماسک‌سازی پیشوندی قابل تشخیص نگه می‌دارد (`AKIA••••T4VB`) و مقادیر غیرراز (نام
  فایل‌هایی که `credential_file_added` گزارش می‌کند، کد معمولی) خوانا می‌مانند.

### افزوده‌شده

- تست سرتاسری خط لوله: مخزن Git موقت واقعی → diff → هر هفت موتور → امتیازدهی، با
  تأیید یافته بحرانی کلید AWS، یافته خطرناک `curl … | bash`، حکم مسدود، نبودن کلید
  خام در همه فیلدهای یافته، و حکم قبول با صفر یافته برای یک تغییر تمیز مستندات.
- تست فهرست قوانین برای `mask_secrets_in`.
- نشان‌های CI / ریلیز / دانلود / پروانه / سکو در `README.md` و `README.fa.md`.
- چک‌لیست «انتشار نسخه» در `CONTRIBUTING.md` (هر تگ باید باینری‌های ویندوز را منتشر
  کند، نه فقط سورس).

## [0.1.0] - 2026-10-17

### افزوده‌شده

- نخستین نسخه عمومی ایجنت‌گارد برای ویندوز (x64): نصب‌کننده NSIS، بسته MSI و فایل
  اجرایی قابل‌حمل، همه تولیدشده توسط GitHub Actions.
- بازبینی تغییرات محلی Git با شش مبنای مقایسه: درخت کاری، تغییرات staged، پایه
  ادغام شاخه، یک کامیت و N کامیت اخیر، به‌همراه امکان شامل کردن فایل‌های
  ردیابی‌نشده.
- فهرست قوانین نسخه ۱ با **۱۴۴ قانون** در هفت موتور — رازها و کلیدهای API (۲۹)،
  دستورات خطرناک (۲۴)، رگرسیون‌های امنیتی (۳۳)، یکپارچگی تست (۱۳)، تغییرات مشکوک
  (۲۰)، زنجیره تأمین (۱۳)، سخت‌سازی CI/CD (۱۲) — هر قانون با عنوان، توضیح و راه
  اصلاح انگلیسی و فارسی.
- ۲۲ هیوریستیک زمینه‌ای فراتر از تطبیق regex (جعل‌نام، اختلاف lockfile، حذف
  گزاره‌ها، نویسه‌های پهنای‌صفر/هم‌شکل، `pull_request_target` + checkout، بلاب‌های
  کدگذاری‌شده و…).
- امتیازدهی ریسک قطعی (۰–۱۰۰) با بازه‌های امن/کم/متوسط رو به بالا/زیاد/بحرانی و
  حکم‌های قبول / نیازمند بازبینی / مسدود.
- اولویت‌بندی یافته‌ها: فیلتر شدت/موتور، جستجوی آزاد، پنل جزئیات با ارجاع CWE،
  اطمینان، قطعه ماسک‌شده، کپی در کلیپ‌بورد، پرش به diff و نمایش در مرورگر فایل.
- نمایش‌دهنده diff یکپارچه با شمارش یافته per فایل و سطرهای علامت‌گذاری‌شده.
- پوشاندن راز با پشتیبان خودکار با مهر زمانی، منوط به تأیید صریح کاربر.
- اجراکننده اختیاری تست پروژه (npm/pnpm/yarn، cargo، go، mvn، gradle، dotnet،
  pytest) منوط به تأیید صریح کاربر.
- بازبینی اختیاری با هوش مصنوعی محلی از طریق Ollama (فقط diffهای ماسک‌شده، بدون API
  ابری) با آزمون اتصال، فهرست مدل‌ها و تجزیه مداراگرانه خروجی.
- برون‌بری گزارش به Markdown، HTML (سازگار با RTL) و JSON به انگلیسی یا فارسی.
- تاریخچه اسکن محلی (تا ۱۰۰ گزارش) با بازکردن مجدد، حذف و پاک‌سازی.
- تنظیمات: زبان (پیش‌فرض انگلیسی / فارسی)، پوسته تیره/روشن، موتورهای پیش‌فرض،
  گلاب‌های ignore، پوشه داده per کاربر، منطقه خطر.
- مستندات دوزبانه (EN + FA): نصب، راهنمای کاربر، مدل امنیتی، راه‌اندازی Ollama،
  معماری و مشارکت.
- CI: typecheck/build فرانت‌اند، `cargo check` راست (اوبونتو + ویندوز)،
  `cargo test`، clippy (مشورتی)، بازتولید و اعتبارسنجی فهرست قوانین.
