# نصب (ویندوز)

> English: [docs/en/installation.md](../en/installation.md)

## نیازمندی‌ها

| جزء | نیازمندی |
|---|---|
| سیستم‌عامل | ویندوز ۱۰ (1809 به بعد) / ویندوز ۱۱، x64 |
| WebView2 | روی ویندوز ۱۱ از قبل نصب است؛ روی ویندوز ۱۰ در صورت نبود، نصب‌کننده دریافت می‌کند |
| Git | هر نسخه اخیر Git for Windows (ایجنت‌گارد مخازن را با libgit2 می‌خواند) |
| دیسک | حدود ۶۰ مگابایت |
| شبکه | پس از نصب نیاز نیست |

## گزینه ۱ — نصب‌کننده NSIS (پیشنهادی)

1. `AgentGuard_<version>_x64-setup.exe` را از
   [صفحه نسخه‌ها](https://github.com/Manixpcshot/agentguard-desktop/releases/latest) دانلود کنید.
2. اجرا کنید. نصب per-user نیازی به دسترسی مدیر ندارد؛ برای نصب سراسری گزینه
   “for all users” را انتخاب کنید (درخواست elevation می‌کند).
3. **AgentGuard** را از منوی استارت اجرا کنید.

نصب بی‌صدا:

```powershell
AgentGuard_0.1.1_x64-setup.exe /S
```

## گزینه ۲ — بسته MSI

برای استقرار سازمانی (Group Policy / SCCM):

```powershell
msiexec /i AgentGuard_0.1.1_x64_en-US.msi /qn
```

## گزینه ۳ — اجرایی قابل‌حمل

`AgentGuard-portable.exe` بدون نصب اجرا می‌شود. تنظیمات، تاریخچه و متادیتای
گزارش‌ها در مسیر زیر ذخیره می‌شوند:

```
%APPDATA%\dev.agentguard.desktop\
```

## راستی‌آزمایی نسخه

هر نسخه توسط GitHub Actions از یک کامیت برچسب‌خورده ساخته می‌شود؛ لاگ ورک‌فلو
ریویژن دقیق سورس را نشان می‌دهد. نسخه نمایش‌داده‌شده در بخش *درباره* برنامه را
با با تگ نسخه مقایسه کنید.

## به‌روزرسانی

نصب‌کننده جدید را دانلود و اجرا کنید — ارتقا در جا انجام می‌شود. تنظیمات و
تاریخچه اسکن در پوشه داده بالا حفظ می‌شوند.

## حذف نصب

- تنظیمات → Apps → AgentGuard → Uninstall، یا
- `Add/Remove Programs` → AgentGuard.

برای پاک‌سازی کامل تاریخچه و تنظیمات، `%APPDATA%\dev.agentguard.desktop` را حذف کنید.

## عیب‌یابی

| نشانه | راه‌حل |
|---|---|
| “WebView2 not found” | [ران‌تایم Evergreen](https://developer.microsoft.com/microsoft-edge/webview2/) را نصب کنید |
| انتخاب‌گر پوشه چیزی نشان نمی‌دهد | پوشه برای اسکن باید داخل مخزن Git باشد؛ باز کردن هر پوشه‌ای ممکن است |
| هشدار SmartScreen | باینری‌های ریلیز هنوز امضای کد ندارند؛ “More info → Run anyway” را بزنید. امضای کد در نقشه راه است |
| Ollama شناسایی نمی‌شود | Ollama را اجرا کنید (`ollama serve`) و مطمئن شوید `http://127.0.0.1:11434` پاسخ می‌دهد |
