# بازبینی اختیاری با هوش مصنوعی محلی (Ollama)

> English: [docs/en/ollama.md](../en/ollama.md)

موتورهای قوانین ایجنت‌گارد با **صفر** سرویس خارجی کار می‌کنند. اگر نظر دوم
نوشته‌شده توسط مدل هم می‌خواهید، به یک سرور محلی [Ollama](https://ollama.com)
متصل شوید.

## راه‌اندازی

1. Ollama را نصب و اجرا کنید (`ollama serve` یا اپلیکیشن tray ویندوز).
2. یک مدل مسلط به کد دریافت کنید، مثلاً:

   ```bash
   ollama pull qwen2.5-coder:7b
   ```

3. در ایجنت‌گارد نمای **بازبینی هوش مصنوعی** را باز کنید و **آزمون اتصال** را
   بزنید. برنامه نسخه سرور و مدل‌های موجود را نشان می‌دهد؛ یکی را انتخاب کنید.
4. *فعال‌سازی بازبینی هوش مصنوعی محلی* را روشن کنید و پس از اسکن، **اجرای
   بازبینی هوش مصنوعی** را بزنید.

## چه چیزی فرستاده می‌شود

فقط یک پرامپت محدود (پیش‌فرض ≤ ۲۴٬۰۰۰ نویسه) شامل:

- یافته‌های قوانین که پیش‌تر تشخیص داده شده‌اند (شناسه‌ها، شدت‌ها، فایل:سطر)، و
- گزیده‌ای از diff فقط با **سطرهای افزوده/حذف‌شده**، با رازهای ماسک‌شده.

هیچ چیز دیگری از دستگاه یا مخزن شما ارسال نمی‌شود و درخواست فقط به میزبان
پیکربندی‌شده می‌رود (پیش‌فرض `http://127.0.0.1:11434`).

## چه چیزی دریافت می‌کنید

خلاصه‌ای کوتاه به‌همراه فهرستی از نکات با شدت و اشاره به فایل، که در نمای
بازبینی هوش مصنوعی نمایش داده می‌شود و در گزارش‌های برون‌بری هم جاسازی
می‌شود. خروجی مدل با مدارا تجزیه می‌شود: اگر JSON معتبر نباشد، متن خام نمایش
داده می‌شود.

## نکته‌ها

- مدل‌های کدنویس بزرگ‌تر (۷B به بالا) کیفیت نکات را محسوس بهتر می‌کنند.
- برای استنتاج فقط-CPU مهلت را بالا نگه دارید (پیش‌فرض ۱۸۰ ثانیه).
- هوش مصنوعی هرگز شدت قوانین یا حکم را تغییر نمی‌دهد؛ فقط مشورتی است.
- اگر Ollama خاموش باشد، اسکن‌ها به‌طور عادی کامل می‌شوند و گزارش قید می‌کند که
  هوش مصنوعی در دسترس نبود.
